MCP is the secure doorway behind the chat.

It lets SIGHT request an approved check without becoming another app your team has to learn. The VNMSFX connection calls Shopify, Gmail, HubSpot or the other approved tools directly. The information does not have to pass through Notion first.

Notion is optional. If it holds business information the system must read, it can be one of the approved sources. If it only displays results, it is simply the company-owned workspace—not a required hub.

If a check must run every morning without anyone asking, a schedule wakes it up. It runs the same approved check and puts the result where the company agreed.

04 / Access and control

The company grants access. The company can remove it.

No passwords in the chat.

The company signs into each approved service on its own secure screen. The company AI never receives a Shopify, Gmail or Meta password.

Read-only comes first.

The first job checks information and returns an answer. Drafting, editing and sending are separate capabilities with separate approval rules.

Missing access is visible.

If a connection expires or information is missing, the system says that directly. It does not quietly report that nothing needs attention.

You do not need to design the system before the call.
